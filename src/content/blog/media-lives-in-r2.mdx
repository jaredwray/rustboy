import { MEDIA } from "../../config";

Agents and humans: do not commit images or videos to git. Media belongs in the designated R2 bucket, uploaded with the wrangler CLI that is pinned as a dev dependency.

## Where files go

The bucket is <code>{MEDIA.bucket}</code>. Objects are public at{" "}
<code>{MEDIA.publicBaseUrl}</code>. A typical key looks like{" "}
<code>blog/post-slug/hero.jpg</code>.

Upload from the repo root:

```bash
pnpm exec wrangler r2 object put rustboy-media/blog/post-slug/hero.jpg \
  --file ./hero.jpg \
  --content-type image/jpeg \
  --remote
```

Then use the public URL in Markdown:

```markdown
![A hero image](https://media.rustboy.ai/blog/post-slug/hero.jpg)
```

Or set `heroImage` in frontmatter to that same absolute URL. Local files under `src/content/` are gitignored on purpose.

## Why not git

Git is a poor object store. Binaries bloat clones, confuse review, and never get a CDN in front of them. R2 is the store; this repo is the words.
