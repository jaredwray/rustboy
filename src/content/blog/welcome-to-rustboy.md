This site is small on purpose. There is a home page, there is a blog, and that is the whole surface.

rustboy.ai is the public notebook: things worth writing down, set in ink and paper rather than a feed. Configuration lives in one file. Posts are Markdown or MDX, checked against a schema so a missing date fails the build instead of shipping a broken page.

## What you will find

- **Home** — a short landing with the latest writing, and the ink simulation behind it.
- **Blog** — posts, newest first, with tags and an RSS feed.
- **About** — who writes this, and how the site is put together.

Images and videos do not live in the git repository. They are uploaded to Cloudflare R2 with wrangler and referenced by URL. If you are an agent working in this repo, read the README before adding media.

## Why a notebook

A feed rewards volume. A notebook rewards deciding that something is finished enough to keep. Posts here should be able to sit for years without apology.
